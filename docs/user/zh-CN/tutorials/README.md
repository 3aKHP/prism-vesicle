# 教程

[English](../../en/tutorials/README.md) | 简体中文

所有[入门页](../README.md)殊途同归,终点都是 `vesicle doctor` 通过、并在项目目录里打开 Vesicle。从这里开始学怎么真正用它创作。

教程假设你已经能启动 Vesicle、`vesicle doctor` 报 `Missing: none`。每篇只引入当下需要的概念,结尾给出检查点。

## 学习路径

1. [第一次对话:界面与门](./first-conversation.md) —— 认识界面,理解"门"这种暂停确认的交互。
2. [在 Workspace 页查看和修改产物](./workspace-page.md) —— 浏览、编辑、校验和管理项目文件,并按需交给外部编辑器。
3. [运行中继续工作](./work-while-running.md) —— 用队列补充主任务,用 `/btw` 做不进入主对话的旁路提问。
4. [第一张角色卡](./first-character-card.md) —— 走完 ETL 工作流 A,产出一张通过校验的 Module A 角色卡。
5. [第一张情景卡](./first-scenario-card.md) —— 基于角色卡产出 Module B 情景卡并校验。
6. [会话恢复与回退](./sessions-and-rewind.md) —— 恢复历史会话,回退到任意一步,任意深度切换候选分支。
7. [为项目建立持久化指令](./persistent-instructions.md) —— 用 `/init`、`/instructions` 和模型工具维护跨会话项目规范。
8. [权限与宿主 Shell](./permissions-and-shell.md) —— 四档工具批准模式,以及何时启用 shell。
9. [联网搜索与图片](./web-search-and-images.md) —— 区分供应商内置搜索与 Tavily,并把剪贴板图片安全地交给视觉模型。
10. [Skills 与 SubAgents](./skills-and-subagents.md) —— 让模型查阅随版本附带的文档,以及把一个有边界的任务交给子运行时。

前八篇覆盖日常创作循环;后两篇覆盖常用的增强能力。命令速查、配置、安全模型等参考内容见[参考区](../reference/README.md)。
