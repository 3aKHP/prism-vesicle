# novel-outline-v3

长篇小说的分层写作纲要工作流。

```
卷纲（计划层）→ 章纲（执行层）→ 场景（写作单元）
两本全局档案：角色成长（世界→角色）、世界观状态（角色→世界）
```

## 何时使用

- 用户要「明确前三章」「写某卷纲要」「把大纲细化到场景级」。
- 已有正文与旧大纲、方法论笔记、设定集并存，需要统一为单一事实基准。
- 需要系统化分配张力、登记伏笔收放、跟踪角色成长与世界观变化。

## 前提

- **正文为先**：已写正文是事实基准，冲突处以正文为准。
- 素材：正文、旧大纲、张力/事件大纲、复盘/方法论笔记、设定集与人物卡、两本档案（若已存在）。
- 无正文时：以用户提供的世界观/人物资料为准；冲突处标【待确认】。

## 流程

### 1. 读齐素材 + 打开档案

正文 → 旧大纲 → 张力/事件大纲 → 复盘笔记 → 设定集/人物卡 → **读取两本档案当前状态**。记录与正文冲突的点。

### 2. 定卷纲（计划层）

套用 `references/templates.md` 卷纲模板：

- 卷名 / 本卷主题（主要写什么）/ 本卷目标（做什么：主线推到哪、收哪些雷、埋哪些新雷）
- 时间跨度 / 涉及人物势力
- **本卷角色弧线声明**（谁从哪到哪，分认知/能力/关系维度）
- **章分配意图**（哪章重哪章轻——不设卷级张力总值，总值在章级定）
- 卷内伏笔收放总表
- 世界观披露/变更重点
- 章列表（每章一句话）

### 3. 逐章定纲（执行层）

对每一章套章纲模板：

1. **章头**：章节/时间/地点/人物/势力/节奏类型/互动关系
2. **完整梗概**：一段话
3. **角色 delta**：本章获得/新知道/关系变化——从档案取起始状态，实现卷弧线的一步
4. **世界观披露与变更**：读者知道什么 / 世界实际变成什么
5. **伏笔收放**：埋/收，标注回收章
6. **张力总值确定**：先按本章性质定总值，再分到场景（见 tension_model）
7. **台词梗概**：对话走向 + 关键对白锚点
8. **逐场景细化**：场景模板字段

### 4. 闭合校验

- 每章：场景点数之和 == 本章总值（分配后一次、定稿前反查一次）
- 卷内：章与章之间有张力曲线（高低交替）
- 伏笔收放闭合
- 角色 delta 串联 == 卷弧线声明
- 世界观变更与档案一致
- 登场密度（每章新名字 ≤ 2）
- 时间线一致

### 5. 回写档案

- 角色成长档案：把本章角色 delta 记入
- 世界观状态档案：把本章世界观变更记入
- 卷纲收尾时核对整卷弧线

### 6. 完成标准

- 卷纲、章纲、场景三级齐全（不用卷的项目可省卷层，直接章纲）
- 每章张力总值确定且有闭合校验记录
- 两本档案已回写
- 待确认项显式列出，不默认替用户拍板

## 边界与非目标

- 不写正文句子——本流程只到「可写基准」。
- 不替用户拍板世界观/关系/成长方向；拿不准标【待确认】。
- 不修改已写正文；只产出纲要文档。
- 档案是唯一事实源：章纲与档案冲突时，先查档案、再改纲要；档案无记录的新事实，先补档案再进章纲。
