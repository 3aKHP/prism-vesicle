# 张力模型（v3）：总值确定 + 闭合校验 + 节奏

> 来源：项目《写作指南》A 节「张力点数模型」与实战复盘，已去项目化。

## 张力总值确定（每章自己定）

不再全局统一 100。**每一章先按自己的性质定张力总值**，再分到场景：

| 章的性质 | 参考总值 |
|----------|:---:|
| 对话 / 推拉章 | 30-40 |
| 高潮 / 决战章 | 40-50 |
| 常规推进章 | 20-30 |
| 过渡 / 氛围章 | 10-20 |

- 开篇章可在同性质基准上给加成（120-150%）。
- 总值定好后，场景分配点数之和必须 == 总值。
- **不需要功能小计**——总值由章的性质决定，场景只是切分；小计是「强行统一 100」时代的拐杖。

## 功能类型（场景级标注用）

| 功能 | 参考点数 | 说明 |
|:----|:---:|:-----|
| 读者落脚 / 世界展示 | ~10 | 入场氛围，低起点 |
| 过渡 | ~5 | 从 A 到 B |
| 人物出场 | ~10 | 建立接触 |
| 疙瘩 / 伏笔 | 15-25 | 让读者「嗯？」 |
| 推拉 / 交锋 | 25-35 | 对话攻防转换 |
| 情感对接 | ~15 | 短暂真诚时刻 |
| 悬疑收线 | ~10 | 转化为未解的问号 |
| 余韵收束 | ~10 | 让章节落下来 |

## 节奏类型

| 类型 | 特征 |
|------|------|
| 对话推拉 | 双人/多人言语攻防为主，句子密度高，张力靠话走 |
| 信息氛围 | 世界观/信息交代为主，张力压低，留给读者落脚 |
| 动作情感 | 事件/打斗 + 情感落点，动作与情绪交替 |
| 混合 | 按场景切换主次，章级标主类型 |

## 闭合校验（必做）

1. 每章 **Σ场景 == 本章总值**。
2. 校验做两次：分配后、细化前一次；细化后、定稿前再反查一次。
3. 不闭合时：优先调过渡/余韵/极简场景的点数，**不要动章总值**（除非用户认可）。
4. 卷内要有张力曲线：章与章高低交替，不能一直紧、也不能一直平。
5. 场景拆分/合并后必须重新反查——「加了场景忘了加总数」是常见漏洞。

## 原则

1. **张力要有曲线**——不是一直紧；要有回落让读者喘口气，也让下一次收紧更有力。放松段落不是空转，也在埋东西。
2. **段落留不留，问三件事**：推剧情吗？建角色吗？埋伏笔吗？三问皆否 = 插曲，张力紧张时必须删。
3. **伏笔倍增**：埋时轻（约 5 点），收时响——「10点事件 + 回收一颗雷 = 30点以上」。埋的时候可忽略、不打断主戏；收的时候读者不用翻回去也想得起。
4. **不要同一章节内埋了又收**——刚埋就爆不是伏笔，是剧透。
5. **分层张力**：卷（分配意图）→ 章（总值）→ 场景（点数），每层逻辑相同：张力要有曲线。

## 登场密度原则

- 每章新增有名字角色 ≤ 2。
- 舞台站不下那么多人；新人物分批进，别让观众认人认到累。
- 功能性角色（售票员、管理员、背景同学）不计入「有名字的人」。

## 正文为先原则

- 事实优先级：已写正文 > 旧大纲 > 人物卡/设定集。
- 冲突以正文为准；正文未覆盖处以用户指示为准。
- 纲要只做「可写基准」，不替用户拍板世界观与关系；拿不准标【待确认】。

## 复盘高频原则（写作阶段对接用）

- 声音先于人出现：先闻其声，再认其人。
- 完整动作链：第一次做某事的人，动作要四环节齐全（掏→看→确认→松气）。
- 短句碎片不是干练：单字成段是 AI 文风，用连接词让信息在句子里流动。
- 台词是肉，背景是米：描写要短小精悍，不是抛弃描写。
- 退场方式和入场一样重要：每段文字都要有方向。
