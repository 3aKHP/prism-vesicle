# 写作纲要模板（v3）：卷纲 / 章纲 / 场景

复制骨架，按字段填。三级结构：卷纲 → 章纲 → 场景。

---

## 一、卷纲

| 字段 | 内容 |
|------|------|
| 卷号 / 卷名 | |
| 本卷主题 | 主要写什么 |
| 本卷目标 | 做什么：主线推到哪、收哪些雷、埋哪些新雷 |
| 时间跨度 | |
| 涉及人物 | 主 / 次 / 提及 |
| 涉及势力 | |
| 角色弧线声明 | 角色 \| 认知 起点→终点 \| 能力 起点→终点 \| 关系 起点→终点 |
| 章分配意图 | 章 \| 一句话 \| 张力档位（重 / 中 / 轻） |
| 卷内伏笔收放 | 伏笔 \| 埋设章 \| 回收章 \| 状态 |
| 世界观重点 | 本卷披露 / 变更重点 |
| 章列表 | 每章一句话 |

## 二、章纲

### 章头

| 字段 | 内容 |
|------|------|
| 章节 | 第 X 章 · 章名 |
| 事件时间 | Day / 时刻 / 季节 |
| 地点 | 主要场景（场景级再细化） |
| 相关人物 | 主 / 次 / 提及 |
| 相关势力 | |
| 节奏类型 | 对话推拉 / 信息氛围 / 动作情感 / 混合 |
| 互动关系 | 角色对 \| 互动量 \| 关系状态 \| 关系走向 |

### 故事层

- **完整梗概**：一段话，本章从哪到哪。
- **角色 delta**（从档案取起始）：角色 | 本章获得 | 本章新知道 | 关系变化
- **世界观披露**（读者知道）：披露项 | 首次/深化 | 载体（对话/旁白/道具/场景）
- **世界观变更**（世界变了）：变更项 | 性质（事件/认知/格局）| 回写档案（是/否）

### 张力

- **本章总值**：____（按本章性质定，附一句理由）
- **场景分配表**：场景 | 点数 | 功能 | 节奏
- **闭合校验**：Σ场景 == 本章总值？是 / 否

### 伏笔收放

伏笔 | 埋/收 | 与档案对照（不冲突？）

### 台词梗概

- **对话走向**：谁和谁聊、聊什么、攻防怎么走。
- **关键对白锚点**：3-5 句，标注为什么重要。

## 三、场景

### 场景 [编号] · [场景名]（[张力点数] 点）

- **时间 / 地点 / 人物 / 势力**：
- **功能**：读者落脚 / 过渡 / 建立接触 / 推拉 / 信息节点 / 情感对接 / 回收 / 余韵（选一或组合）
- **张力**：点数 + 一句话说明升降方向
- **节拍**：1. 2. 3. ……（逐步的事件/对话推进，细到可照写；关键台词直接摘录）
- **台词锚点**：关键台词 1-3 句，标注为什么重要
- **伏笔**：本节埋设了什么 / 回收了什么
- **世界观披露/变更**：如有，本节披露或改变了什么
- **写作注意**：对接项目复盘教训（声音先于人出现、完整动作链、短句别碎、台词是肉背景是米、退场和入场一样重要）
- **节奏**：紧 / 松 / 收（一句话）
- **字数**（可选）：预计字数

## 四、待确认清单

逐条给出现状与建议，等用户拍板。示例：

- 考试日期：正文写「四天后」（Day 5）vs 事件大纲按 Day 6 —— 建议统一 Day 5
- 房号：正文「三〇七」vs 人物卡「三〇二」—— 正文为准
