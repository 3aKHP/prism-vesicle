# 两本全局档案（living documents）

> 原则：档案是全项目唯一事实源。卷纲/章纲从这里取数，写完回写。章纲与档案冲突时先查档案；档案无记录的新事实，先补档案再进章纲。

---

## 一、角色成长档案（世界 → 角色）

**记录：世界如何塑造角色**——认知、能力、关系网的累积变化。

每个主要角色一条：

| 角色 | 起始认知 | 起始能力 | 起始关系网 | 卷1变化 | 卷2变化 | …… | 当前状态 |
|------|---------|---------|-----------|---------|---------|-----|---------|
|      |         |         |           |         |         |     |         |

**维护规则：**

1. 每章结束后回写本章角色 delta（获得 / 新知道 / 关系变化）。
2. 卷纲的角色弧线声明必须与档案一致：**弧线是计划，档案是执行记录**。
3. 认知的「知道/不知道」是重点：某人**何时**知道某真相，必须进账——「知道」的时间点错了，整条线就塌。
4. 能力变化要有载体（学了什么/练了什么/得到了什么），不能空写「变强了」。

---

## 二、世界观状态档案（角色 → 世界）

**记录：角色如何改变世界**——势力、地理、真相、认知、事件后果的累积变化。

每个可变世界要素一条：

| 世界要素 | 初始状态 | 变化记录（章/卷 + 谁造成的） | 当前状态 |
|---------|---------|---------------------------|---------|
| 势力格局 | | | |
| 地理 / 地点 | | | |
| 真相 / 秘密 | | | |
| 魔法 / 技术认知 | | | |
| 重大事件后果 | | | |
| ……（按项目扩展） | | | |

**维护规则：**

1. 章纲的「世界观变更」项必须回写，不能「变了没人记账」。
2. 任何角色行为造成的实质变化都要进账——哪怕是小变化（某件道具损坏、某人知道了一个秘密）。
3. 后续章节的世界状态从档案取，不许与档案冲突。
4. 变更分性质：事件（发生了什么）/ 认知（谁知道/知道了什么）/ 格局（势力/结构变了）——性质不同，回写的字段不同。

---

## 校验清单（每次定纲后跑一遍）

1. 章角色 delta 串联 == 卷弧线声明？
2. 世界观变更已全部回写？
3. 登场密度达标（每章新名字 ≤ 2）？
4. 张力闭合（Σ场景 == 章总值）？
5. 时间线一致？
6. 「知道」的时间点无冲突？
